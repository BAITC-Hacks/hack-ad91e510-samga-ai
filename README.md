# Samga AI — «Аким на 5 часов»

Рабочие интерактивные прототипы HackAlem на едином датасете организаторов. Это стадия проектирования: сервер и настоящий AI-анализ ещё не подключены.

## Быстрый запуск

Откройте `index.html` в браузере. Интернет, установка пакетов и ключи для макетов не нужны. Альтернатива: `python -m http.server 8080 --bind 127.0.0.1`, затем http://127.0.0.1:8080.

Доступны три самостоятельных варианта:
- **Карта города** — районы, слои, состояние до/после, выбор стратегии, условие «школа в Нуре», ручной редактор, сравнение и экспорт.
- **Лаборатория решений** — стратегии, бюджет и результат, сравнение компромиссов.
- **Рабочая панель** — каталог 14 мер, выбор пяти решений, районы, ограничения и расчёт.

Карта схематическая: границы и размещение объектов условные. Пять районов соответствуют учебному датасету, а не актуальному административному делению. Текст обоснования демонстрационный и не является ответом LLM. Расчёты выполняются JavaScript в браузере. HTML-файлы автономны; дублирование модели между ними временное.

## Демонстрация

1. Откройте карту, выберите Нуру: исходно школы 38, медицина 35 — ниже порога 40.
2. Перейдите к решениям, выберите сохранение резерва: стоимость 66, Score 56.572625, критических показателей 0.
3. Закрепите школу в Нуре: стоимость 80, Score 56.69056.
4. Сравните планы, откройте паспорт района, покажите улучшения и потери по отдельным показателям.
5. Измените меры вручную: недопустимый набор не получает итоговый Score.

Подробный сценарий: [docs/09_MAP_DEMO_SCENARIO.md](docs/09_MAP_DEMO_SCENARIO.md).

## Правила модели

Бюджет 100; ровно пять разных мер; максимум две меры одного направления. Проверяются несовместимости M1/M3, M4/M7 в одном районе, M5/M13 в одном районе. Эффекты умножаются на (8 − лаг)/8, затем добавляются синергии без лага; значения ограничиваются 0–100.

Score = 0.7 × средний балл с весами населения + 0.3 × минимальный районный балл − количество показателей строго ниже 40.

Рабочая трактовка — подробные правила DOCX. Неоднозначность PDF о пяти направлениях требует ответа организаторов. Исходный Score: 52.55768; пример организаторов: 56.54307 при расходе 95.

## Воспроизводимый поиск стратегий

Python 3 + NumPy:

```sh
python -m pip install -r analysis/requirements.txt
python analysis/audit-strategies.py
```

Скрипт использует `analysis/model-input.json` и перезаписывает `analysis/strategy-audit.json`. Полный перебор по принятой трактовке DOCX: 694395 допустимых назначений районов. Максимум Score: 57.236735 при расходе 98. Это оптимум учебной модели, не прогноз реального города.

## Проверено и что осталось

Ранее проверены в браузере выбор стратегии, закрепление школы, ручное редактирование, карты и сравнение; расчёты контрольных сценариев сопоставлены с независимым расчётом. Перед этим коммитом все три автономных HTML открыты в Edge без ошибок JavaScript; контрольные Score проверены, полный поиск успешно повторён.

До готового конкурсного продукта нужны серверный валидатор, настоящий AI-разбор с обработкой ошибок, интеграционные проверки, запуск командой по README и сдача на платформе. Галерея из десяти новых концепций пока не завершена и в этот коммит не входит.

Аудит требований и вопросы команде: [docs/08_TRACK_REVIEW.md](docs/08_TRACK_REVIEW.md). Материалы предназначены для приватного командного репозитория.
