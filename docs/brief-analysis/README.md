# Разбор ТЗ «Аким на 5 часов»

Самостоятельный локальный сайт для команды Samga AI: требования, данные, формула, четыре разобранных сценария, план и открытые вопросы. Это рабочая тетрадь до реализации конкурсного продукта; живой AI на сайте не вызывается.

## Запуск

Из этой папки:

```sh
python3 -m http.server 4193 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4193/. Новые зависимости не нужны. Сервер слушает только локальный компьютер. Запуск через `file://` не поддерживается из-за ES-модулей.

## Что внутри

- `dist/index.html` — семь разделов, привязка к страницам/разделам оригиналов.
- `dist/data.mjs` — показатели, районы, меры и четыре сценария из/на основе DOCX.
- `dist/model.mjs` — проверка правил и воспроизводимый расчёт для аналитических примеров.
- `dist/app.mjs` — навигация, просмотр районов, фильтр каталога и разбор сценариев.
- `dist/assets/` — три сгенерированные иллюстрации. Промпты в `IMAGE-PROMPTS.md`; использован встроенный image_gen.
- `dist/sources/` — неизменённые копии исходных PDF и DOCX.
- `sources/` — текстовые извлечения для проверки содержания; исходные файлы не редактировались.

## Проверки

```sh
node --test test/model.test.mjs
node --check dist/app.mjs
node --check dist/model.mjs
node --check dist/data.mjs
```

Эталоны: база `52.55768`, пример DOCX `56.54307` при стоимости 95. Округление только в отображении.

Правила расчёта основаны на DOCX: ровно 5 мер, максимум 2 в направлении. Расхождение с PDF о пяти направлениях отмечено явно и не объявлено решённым. Сценарии не претендуют на оптимальность. Иллюстрации не являются географическими картами или реальными показателями города.

Сайт без общего редактирования и внешней публикации. План ролей — предложение,
а не подтверждение принятых участниками задач. Эта копия включена в конкурсный
репозиторий как аналитический этап; происхождение раскрыто в [SOURCES.md](../../SOURCES.md).
Исходная локальная рабочая тетрадь и team-desk при переносе не менялись.
