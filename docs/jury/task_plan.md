# Сильная и проверяемая конкурсная версия

Цель Карима: закрыть оставшиеся пробелы и сделать понятный, технологичный продукт,
пригодный для убедительной демонстрации руководителю и независимой оценки.

Выбранный подход: усилить существующую модель и поиск, а не вводить новую архитектуру.
Основной сценарий интегрируется параллельной задачей в samga-integration.
Эта задача владеет briefing/, scripts/jury-check.mjs и docs/jury/ в отдельной ветке.

## Приёмка
1. [in_progress] Зафиксировать критерии, ограничения и разделение параллельной работы.
2. [pending] Итог для руководителя: одинаковый бюджет, варианты, конкретная польза,
   цена компромиссов, оставшиеся критические показатели, источники и границы модели.
   Все числа пересчитываются из выбора; произвольный/устаревший AI не попадает в итог.
3. [pending] Автономные HTML/JSON артефакты выбранного решения, пригодные для печати
   и повторного расчёта. Проверить кодирование текста и работу без внешней сети.
4. [pending] Воспроизводимая независимая проверка 5 критериев ТЗ и сложных случаев.
