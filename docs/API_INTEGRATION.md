# План подключения API к панели «АКИМ»

**Статус на 23.09.2026: запланировано, не подключено.** В ветке
`karim/simulator` панель работает как локальная демонстрация без ключа
и показывает заранее подготовленные объяснения. Команда собирается подключить
OpenAI API позже, используя хакатонный кредит около $50. Ключ ещё не добавлен.

## Что подключить

1. Вынести сетевые вызовы в серверный слой. Браузер отправляет выбранные меры,
   районы и вопрос акима на собственный API. `OPENAI_API_KEY` и
   `OPENAI_MODEL` читаются сервером из окружения; ключ никогда не
   попадает в Git, HTML, JavaScript браузера или localStorage.
2. Использовать **одну** модель расчёта:
   `docs/brief-analysis/dist/model.mjs`. Сервер заново проверяет
   пять разных мер, районы, бюджет до 100, максимум две меры направления,
   несовместимость, а затем вычисляет бюджет, Score и показатели. Браузерные
   числа не считаются доказательством результата.
3. Подключить помощника к проверяемым действиям: объяснить текущий план,
   сравнить два плана, найти вариант по заданной цели, показать источники.
   Модель ИИ может распознать запрос и выбрать действие, но численные факты
   и текст о них сервер строит из проверенного расчёта. Предложение ИИ
   применяется к плану только после явного выбора пользователя.
4. Показать статус честно: без ключа работают расчёт, сравнение и демопоказ;
   свободный диалог сообщает, что API ожидает подключения. При ошибке API
   исходный план остаётся доступным.
5. Ограничить затраты и задержку: отдельный проект для хакатона, лимит расходов
   в кабинете провайдера, ограничение размера запроса и ответа, тайм-ауты и
   частота вызовов. Перед использованием кредита команда выбирает модель и
   проверяет фактические тарифы.

## Граница точности

Датасет учебный. Проверенная модель считает восемь кварталов (два года).
ИИ не должен выдавать её результат за фактический прогноз города или
экстраполировать числа на 1, 5 и 10 лет. Международные источники помогают
объяснить механизм и ограничения, но не калибруют коэффициенты DOCX.
У Сарайшыка нет значений показателей — их нельзя додумывать.

## Проверка перед включением

- Без ключа панель и расчёт продолжают работать; статус ИИ понятен пользователю.
- Сервер отвергает подменённые Score, бюджет и районные показатели.
- Ответ ИИ с выдуманным числом или показателем не становится выводом панели.
- Выбор пяти мер, перенос районов и сравнение используют тот же результат,
  что тесты общей модели.
- Запрос на 1, 5 или 10 лет не получает численного прогноза.

Ответственные за ключ и фактический лимит расходов, а также трактовку
расхождения PDF/DOCX о пяти направлениях, определяются командой.
