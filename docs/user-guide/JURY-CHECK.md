# Проверить платформу самостоятельно

## 1. Запуск

Нужен Node.js 24+. Из корня репозитория: `node backend/server.mjs`.
Открыть http://127.0.0.1:4197/ → «Открыть демонстрацию». Аккаунт и npm install не нужны. Интернет используется для карты; расчётная модель и её данные локальные.

## 2. Повторяемый результат

«Составить свой план» → M1 Нура, M4 Сарыарка, M7 Нура, M10 Нура, M12 весь город.
Ожидать: расход83, резерв17, индекс55,61 (точно55.60722), одно критическое значение — медицина Нуры35. Представлены все пять направлений.

После четырёх мер итогового Score нет. Повтор меры, третья мера одного направления, превышение бюджета и несовместимые проекты блокируются с объяснением. Значение ровно40 не является критическим.

## 3. Сравнение и выгрузка

«Подбор и отчёт» переносит полный план. Скачать HTML и JSON; значения совпадают с панелью. HTML можно открыть автономно. Вернуться на карту — те же пять мер и те же районы восстанавливаются.

В поиске можно выбрать минимальные расходы, убрать критические показатели, закрепить школу в Нуре. Оптимальность относится только к заданной конечной модели и выбранным ограничениям.

## 4. Мобильные роли

Открыть `/mobile/`: две роли и реальные iOS-скриншоты, доступные на любой ОС. Это просмотр подтверждённых экранов, не эмуляция iPhone в браузере.
Для запуска нативных приложений — [mobile/README.md](../../mobile/README.md). macOS/Xcode требуются только этому этапу. У жителя можно пройти пример обращения без камеры и ключа AI. Службам ничего не отправляется.

## 5. ИИ

Во втором терминале: `node assistant-service/server.mjs`. В веб-панели открыть круглую кнопку помощника → «Настройки» и подключить OpenAI. Ключи не входят в Git и не сохраняются браузером.
Собрать план и спросить «Почему Нура?» или «Сравни варианты». Ответ должен объяснять реальные выбранные меры и рассчитанные числа, показывать риски и компромисс. Числа вычисляются движком вне LLM.

В локальной проверке автора подтверждены два настоящих текстовых ответа GPT. Голос ElevenLabs возвращал ошибку; живое распознавание речи не подтверждено. Новая установка без API-ключа покажет отсутствие подключения, а не поддельный ответ. Отдельный старый `/api/analyze` работает по конфигурации backend; его demo-режим не является доказательством работы нового помощника.

## 6. Машинная проверка

```sh
node scripts/jury-check.mjs --url http://127.0.0.1:4197
```

`deterministicPassed: true` подтверждает перечисленные HTTP-проверки. `requiredAiVerified: false` без `--live-ai` ожидаемо: внешняя модель не вызывалась. Флаг `--live-ai` относится к отдельно настроенному структурированному backend `/api/analyze`, а не к плавающему ассистенту; не смешивайте эти проверки.

## Граница соответствия ТЗ

PDF требует пять направлений; DOCX допускает минимум три при максимуме двух мер одной группы. Первый пример покрывает все пять, валидатор следует DOCX. Данные синтетические, горизонт два года; официальные данные, межсистемная синхронизация, реальная экономия и факт сдачи не заявляются.
