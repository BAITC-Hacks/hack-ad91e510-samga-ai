# АКИМ / SAMGA AI — мобильные роли

Это два **отдельных локальных iPhone-демо**. Они дополняют веб-симулятор, но не подключены к нему, друг к другу или к реальным городским системам.

| Роль | Проект | Что можно показать |
|---|---|---|
| Аким | `заготовки/АКИМ-iOS` | Наблюдение за событиями, картой и чатами; локальный контроль; готовый пример проекта поручения |
| Житель | `citizen-demo-ios` | Фото, голос или текст → проверка адреса → локальное демо-обращение → статусы |

## Аким: наблюдать и подготовить демо-поручение

1. На входе нажмите **«Открыть демоверсию»**. Поля почты и пароля не используются: настоящая авторизация не подключена.
2. Во вкладке **«События»** откройте карточку. В ней есть утренняя сводка, фильтры и подробности учебных городских историй.
3. Нажмите **«Взять на контроль»**. Кнопка меняется на **«На контроле»**; это состояние сохраняется только в памяти текущего сеанса.
4. Во вкладке **«Карта»** выберите условный объект и используйте **«Взять на контроль»**. Apple Maps показывает пять демонстрационных точек; геопозиция пользователя не запрашивается.
5. Во вкладке **«Помощник»** откройте готовый пример **«Проект поручения»**, прочитайте задачу, ответственного и срок, затем нажмите **«Сохранить черновик»**. Это заранее подготовленный текст, не генерация внешней AI-моделью и не отправка поручения исполнителю.

Дополнительно доступны **«Чаты»**: сообщения и вложенный **«План работ»** работают локально. Для выхода откройте меню **«АКИМ»** вверху ленты и нажмите **«Вернуться ко входу»**.

## Житель: создать и проследить демо-обращение

1. Откройте вкладку **«Мой район»** и выберите **«Фото»**, **«Голос»** или **«Текст»**. Все действия ведут в единый черновик.
2. Добавьте материал и описание. На физическом iPhone **«Камера»** открывает системную камеру; в симуляторе используйте **«Фото»** из галереи или **«Посмотреть пример»**. Голос записывается локально, максимум две минуты.
3. Нажмите **«Продолжить»**. На экране **«Осталось указать место»** проверьте адрес: фотография сама по себе не определяет место.
4. Нажмите **«Отправить в демо»**. Экран покажет номер, затем нажмите **«Открыть обращение»**.
5. На карточке обращений используйте **«Демо: показать следующий этап»**, чтобы вручную пройти получение, рассмотрение, план, работу и отчёт. В финале выберите **«Да, всё исправлено»** или **«Проблема осталась»**.
6. Во вкладке **«Мои обращения»** видны сохранённые на устройстве карточки; в карточке можно нажать **«Следить»**. Фоновых уведомлений нет.

Кнопка **«Подключение ИИ»** находится во вкладке **«Профиль»**. Только после ввода пользователем собственного ключа становится доступна **«Разобрать с ИИ»**. Без ключа это неработающая AI-функция: материалы можно сохранить и отправить в демо без анализа.

## Что здесь настоящее, а что учебное

| Возможность | Статус |
|---|---|
| Интерфейс, переходы, локальные черновики и статусы жителя | Локально реализованы; обращения сохраняются на устройстве |
| Контроль события у акима, чаты и черновики помощника | Локально реализованы только в текущем сеансе |
| Камера | Доступна на физическом iPhone; в симуляторе требуется галерея или учебный пример |
| Карты | Нужны Apple Maps и сеть; точки и координаты учебные |
| Анализ фото/голоса с AI | Код предусмотрен, но живой запрос не подтверждён без пользовательского ключа |
| Городские службы, реальные поручения, официальные статусы | Не подключены |
| Синхронизация жителя с кабинетом акима и веб-панелью | Не подключена |

Все истории, адреса, сроки, карточки и изображения в демонстрациях синтетические. Учебная иллюстрация не является фотографией выполненной работы.

## Установка и запуск

Для обоих проектов нужны Xcode, iOS Simulator и уже установленный XcodeGen. Внешних библиотек не заявлено. Команды ниже взяты из README проектов; в этой вычитке их повторно не запускали.

### АКИМ для iPhone

```sh
cd /путь/к/HackatonDay/заготовки/АКИМ-iOS
xcodegen generate --spec project.yml
xcodebuild -project AKIM.xcodeproj -scheme AKIM -configuration Debug \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,id=AE8443B5-4E81-443C-9C92-C7AC94672F87' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
xcrun simctl install AE8443B5-4E81-443C-9C92-C7AC94672F87 \
  build/Build/Products/Debug-iphonesimulator/AKIM.app
xcrun simctl launch AE8443B5-4E81-443C-9C92-C7AC94672F87 kz.hackalem.akim
```

Проектный README заявляет `BUILD SUCCEEDED`, установку и запуск на указанном симуляторе. Для открытия сразу с ленты добавьте `--demo` после bundle ID. На физическом iPhone потребуется подпись Apple Developer или Personal Team.

### АКИМ Житель

```sh
cd /путь/к/HackatonDay/citizen-demo-ios
xcodegen generate --spec project.yml
xcodebuild -project AKIMCitizen.xcodeproj -scheme AKIMCitizen \
  -configuration Debug -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,id=BDA809D4-779E-4256-9D49-6F451B2564D2' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
swift test --scratch-path /private/tmp/akim-citizen-swift-tests
```

README задаёт отдельный симулятор с bundle ID `kz.hackalem.akim.citizen.demo`, чтобы не смешивать его с основным демо. Успешная установка на этот симулятор и визуальный проход экранов в рамках этой документации **не подтверждены**: перед показом их нужно проверить на конкретном Mac.

## Неподтверждённые UI-доказательства

Последнее подтверждение владельцев мобильных задач: приложение акима получило короткий маршрут на входе и подпись «Учебное демо · поручения сохраняются локально»; финальная сборка успешна. До сбоя Device Hub вручную осмотрены четыре вкладки. Повторный запуск финальной сборки и XCTest runtime не подтверждены.

У приложения жителя есть локальный commit `b522770`, успешная сборка и 5/5 тестов. Полный пользовательский проход не подтверждён: Device Hub/CoreSimulator не обработал установку и запуск. Общие службы и чужие симуляторы не перезапускались.

- В README акима есть подтверждения сборки и снимки входа/кабинета, но в этой задаче не выполнен новый прогон четырёх вкладок и сценария «Проект поручения».
- Для жителя исходники и README описывают маршрут, но самостоятельный запуск, установка и скриншоты текущего состояния здесь не проверялись.
- Живые OpenAI-запросы, распознавание речи и анализ произвольной фотографии не подтверждены без ключа пользователя.

Для показа безопаснее называть оба приложения «локальными демонстрациями» и проговаривать границы, а не представлять учебные статусы как ответы реальных служб.
