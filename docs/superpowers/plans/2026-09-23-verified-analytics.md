# Verified Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Reproducible simulation, constrained search, comparison, sourced evidence and auditable assistant facts.
**Architecture:** Existing DOCX model remains the sole scoring engine. New pure modules generate content-addressed snapshots and facts, enumerate valid plans, and refuse unsupported forecast horizons. AI integration follows credential decision; no secrets are created.
**Tech Stack:** Node.js >=24; built-in crypto, worker_threads, HTTP and node:test; no new npm dependencies.
**Spec:** Approved design in conversation: exact scoring separated from sourced evidence and uncalibrated long-term hypotheses.

## Global Constraints
Budget 100; exactly five distinct measures; max two/category; all DOCX conflicts and synergies; 8 quarters; scores not real-world units.
No automatic budget replenishment. No invented forecasts for 1/5/10 years. No numerical claims generated by an LLM accepted as model output.
No mutation of caller data. Same choices/model produce same scenario identity irrespective of order.
Preserve team frontend and backend contracts; make integration explicit.
