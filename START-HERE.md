# Запуск SAMGA AI для эксперта

1. Распакуйте весь ZIP. Нужен установленный Node.js 24 или новее.
2. Windows: откройте START-WINDOWS.bat. macOS: START-MAC.command.
   Либо в терминале из папки проекта: `node backend/server.mjs`.
3. Откройте **http://127.0.0.1:4197/**. Оставьте окно сервера открытым.
   Остановка — Ctrl+C. Никаких аккаунтов и npm install для запуска не нужно.

Если порт занят: `python3 start-demo.py` выберет свободный порт и откроет браузер
(этот вспомогательный способ требует также Python 3). Запуск HTML двойным кликом
не подходит — приложению нужен сервер расчёта.

Нажмите «Выбрать 5 мер», добавьте меры и районы, затем «Рассчитать результат».
Сравните показатели и запросите AI-объяснение. В чистом ZIP AI работает в явно
помеченном деморежиме; живой доступ команда настраивает локально в backend/.env.
Ключи и личные аккаунты участников в архив не входят.

Для эталона организаторов: M7, M8, M10 → Нура; M12 → весь город; M5 → Сарыарка.
Ожидается расход 95, Score 56.54307 (на экране 56,54).
Для карты нужен интернет и WebGL. Расчёт и таблицы работают без внешних тайлов.

Полная инструкция и ограничения — [README.md](README.md).
