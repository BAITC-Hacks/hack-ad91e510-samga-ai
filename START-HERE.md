# Как посмотреть макет Астаны

Это выбранный командой макет ASTANA / City Lab для «Аким на 5 часов».

## Сначала посмотреть картинку

Откройте `demos/astana-city/preview.png`. Для картинки ничего устанавливать не нужно.

## Запустить интерактивную карту

1. Полностью распакуйте ZIP в обычную папку.
2. Если Python 3 уже установлен, ничего устанавливать не нужно.
   Если его нет — установите с https://www.python.org/downloads/.
3. **Windows:** дважды нажмите `START-WINDOWS.bat`.
   **macOS:** откройте `START-MAC.command`.
4. Макет откроется в браузере. Окно запуска оставьте открытым.
   Остановить сервер можно сочетанием `Ctrl+C` в этом окне.

Если macOS не открывает `.command`, запустите Terminal, введите `python3`
с пробелом, перетащите туда `start-demo.py` и нажмите Enter.
Linux: `python3 start-demo.py` из распакованной папки.
Если браузер не открылся автоматически, скопируйте адрес из окна запуска.

Сервер сам выберет свободный порт и работает только на вашем компьютере.
Нужен интернет для карты и браузер с WebGL. npm, ключи API и аккаунты
в картографических сервисах не нужны. Двойной клик по `index.html` не подходит.

## Что попробовать

- Нажмите «Показать результат»: индекс изменится с 52,6 на 55,7.
- Выберите район, переключите «Город / Районы / Парки» и 2D/3D.
- Откройте Сарайшық: для него честно показано отсутствие данных.

Это демомакет с фиксированным планом. Выбор своих пяти решений и живой AI-анализ
ещё не реализованы. Показатели учебные.
