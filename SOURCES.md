## Подготовленные компоненты, которые здесь ещё не используются

Ранее подготовленные визуальные заготовки ARLAN (вход, основной экран, карта Казахстана
и Three.js) в этот этап не включены. Если команда использует их позже, нужно отдельно
добавить сведения о происхождении, лицензиях и новых изменениях. Они не объявляются
созданными с нуля на соревновании.

## Внешние зависимости

Аналитический сайт и HTML-прототипы не устанавливают npm/pip-пакеты и не обращаются к внешним API.
Используются браузерные HTML/CSS/JavaScript, встроенные модули Node.js и стандартный
HTTP-сервер Python. Ключи и реальные пользовательские данные не требуются.

## Интерактивные прототипы

Три HTML-прототипа, аудит ТЗ и поиск стратегий подготовлены с помощью Codex на хакатоне. Данные перенесены из предоставленного DOCX; карта условная. Сервер и реальный AI-анализ не подключены. Поиск в analysis/audit-strategies.py использует NumPy; зависимости указаны в analysis/requirements.txt.

## Backend Меру (meru/ai)

Backend, контракты, тесты и документация подготовлены Меру с помощью Codex.
Адаптер использует существующий engine Карима без изменения формулы.
Интеграция Responses API сверена с официальной документацией OpenAI:
https://developers.openai.com/api/docs/guides/structured-outputs
Автотесты подменяют транспорт OpenAI; деморежим не является вызовом LLM.

## Проверяемая аналитика

Серверные факты, сравнение, поиск, карточки первоисточников, помощник и рабочий экран реализованы с Codex в ходе хакатона. Первоисточники и дата проверки записаны в analytics/evidence.mjs. Тексты карточек — краткие пересказы публичных описаний; они не использованы как коэффициенты модели. Живой AI-вызов отложен по решению команды.
