## Выбранный макет ASTANA / City Lab

23.09.2026 по поручению Карима перенесён локальный макет
`HackatonDay/заготовки/astana-city-demo` в `demos/astana-city/` как основа
дальнейшей доработки командой. HTML, CSS, стиль, библиотека и изображения
сохранены; в `app.mjs` изменены только пути к общей модели и локальной геометрии.

- Интерфейс макета подготовлен с помощью OpenAI Codex. AI API в нём пока нет.
- `astana.geojson` — шесть объектов Астаны, извлечённых из ранее подготовленного
  `заготовки/Карта/Map-KZ.geojson` (исходный компонент ARLAN). Это повторно
  используемая заготовка; её география не объявляется созданной на соревновании.
  Актуальность границ и исходная лицензия набора отдельно не подтверждены.
- MapLibre GL JS 5.6.2 поставляется локально с [лицензией](demos/astana-city/vendor/LICENSE.txt).
- `base-style.json` основан на `https://tiles.openfreemap.org/styles/dark`.
  Тайлы, шрифты карты и спрайты загружаются из OpenFreeMap; атрибуция
  OpenFreeMap / OpenMapTiles / OpenStreetMap сохранена на карте.
- Изображения `preview.png`, `districts-preview.png`, `mobile-preview.png` —
  снимки исходного локального макета, а не сгенерированные виды города.
- Сценарий `coverage`, показатели и расчёт используются из общей модели
  `docs/brief-analysis/dist/`; синтетические значения не являются статистикой города.

## Подготовленные компоненты, которые здесь ещё не используются

Ранее подготовленные визуальные заготовки ARLAN (вход, основной экран, полный виджет
карты Казахстана и Three.js) не включены; из геометрии карты используются только
шесть контуров Астаны, описанные выше. Если команда использует остальные части позже, нужно отдельно
добавить сведения о происхождении, лицензиях и новых изменениях. Они не объявляются
созданными с нуля на соревновании.

## Внешние зависимости

Аналитический сайт не обращается к внешним API. Макет карты обращается к
OpenFreeMap за картографическими ресурсами. Оба сайта не требуют установки
npm/pip-пакетов. Используются браузерные HTML/CSS/JavaScript, встроенные модули
Node.js и стандартный HTTP-сервер Python. Ключи и реальные пользовательские данные
не требуются; в макете дополнительно нужна поддержка WebGL.
## Backend Меру (meru/ai)

Backend, контракты, тесты и документация подготовлены Меру с помощью Codex.
Адаптер использует существующий engine Карима без изменения формулы.
Интеграция Responses API сверена с официальной документацией OpenAI:
https://developers.openai.com/api/docs/guides/structured-outputs
Автотесты подменяют транспорт OpenAI; деморежим не является вызовом LLM.
