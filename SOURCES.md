## Выбранный макет ASTANA / City Lab

23.09.2026 по поручению Карима перенесён локальный макет
`HackatonDay/заготовки/astana-city-demo` в `demos/astana-city/` как основа
дальнейшей доработки командой. HTML, CSS, стиль, библиотека и изображения
сохранены; в `app.mjs` изменены только пути к общей модели и локальной геометрии.

- Интерфейс макета подготовлен с помощью OpenAI Codex. AI API в нём пока нет.
- `astana.geojson` — шесть объектов Астаны, извлечённых из ранее подготовленного
  `заготовки/Карта/Map-KZ.geojson` (исходный компонент ARLAN). Это повторно
  используемая заготовка; её география не объявляется созданной на соревновании.
  Актуальность границ и исходная лицензия набора отдельно не подтверждены.
- MapLibre GL JS 5.6.2 поставляется локально с [лицензией](demos/astana-city/vendor/LICENSE.txt).
- `base-style.json` основан на `https://tiles.openfreemap.org/styles/dark`.
  Тайлы, шрифты карты и спрайты загружаются из OpenFreeMap; атрибуция
  OpenFreeMap / OpenMapTiles / OpenStreetMap сохранена на карте.
- Изображения `preview.png`, `districts-preview.png`, `mobile-preview.png` —
  снимки исходного локального макета, а не сгенерированные виды города.
- Сценарий `coverage`, показатели и расчёт используются из общей модели
  `docs/brief-analysis/dist/`; синтетические значения не являются статистикой города.

## Внешние зависимости

Аналитический сайт не обращается к внешним API. Карта обращается к
OpenFreeMap за картографическими ресурсами. Продукт не требует установки
npm/pip-пакетов: браузерные HTML/CSS/JavaScript и встроенные модули Node.js.
Python используется только в необязательном запускаторе. Для расчёта ключи
и реальные пользовательские данные не требуются; для карты нужен WebGL.
Для живого AI нужен командный серверный OpenAI API-доступ.

Backend, контракты, тесты и документация подготовлены Меру с помощью Codex.

https://developers.openai.com/api/docs/guides/structured-outputs
Автотесты подменяют транспорт OpenAI; деморежим не является вызовом LLM.

## Локальная интеграция ASTANA / City Lab

Карим (kmakhutov93-ai), с помощью Codex, объединил выбранную карту `8fa0fdf`
с backend Меруерт `12b49e0` и analytics `4ecc591`/`74260c4`. Перенос выполнен
через cherry-pick с исходным авторством и ссылками на оригинальные коммиты.
Frontend Аслана `e520143` включён с полной историей; основной интерфейс использует
его функции ограничения выбора и экранирования из `frontend/lib/scenario.mjs`
и `frontend/lib/format.mjs`. Исходное мини-ТЗ Аслана `b5738e7` сохраняется в истории.

Новая работа интеграции: диалоги выбора/результата на выбранной карте, контракт
сессии, сброс устаревших ответов, единый loopback запуск, проверки и документация.
Ранние прототипы PR #3 не заменяют выбранный дизайн. Ветка `karim/simulator`
и работа `demos/astana-story` не изменялись.

Детерминированный расчёт и UI подтверждены тестами и браузерным проходом.
Живой OpenAI в момент подготовки интеграции не подтверждён; режим demo
не выдаётся за LLM. Проверяемые числа всегда рассчитывает существующий engine.

## Проверяемая аналитика

Серверные факты, сравнение, поиск, карточки первоисточников, помощник и рабочий экран реализованы Меруерт с Codex в ходе хакатона. Первоисточники и дата проверки записаны в analytics/evidence.mjs. Тексты карточек — краткие пересказы публичных описаний; они не использованы как коэффициенты модели. Живой AI-вызов на момент интеграции не подтверждён.
