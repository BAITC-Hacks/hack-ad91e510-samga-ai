# Начать здесь — для команды и её ИИ

**Текущий интерфейс — АКИМ, `demos/astana-story/`, ветка `karim/simulator`.** Старый `demos/astana-city/` сохранён как предыдущий этап и источник ресурсов карты; он больше не основной пользовательский вход.

1. Прочитайте [README](README.md): запуск, реальные кнопки, пример из пяти направлений и ограничения.
2. Из корня репозитория запустите `python3 -m http.server 4196 --bind 127.0.0.1`.
3. Откройте [вход АКИМ](http://127.0.0.1:4196/demos/astana-story/) → «Открыть демонстрацию».
4. Проверьте собственный план: M1 Нура, M4 Сарыарка, M7 Нура, M10 Нура, M12 весь город. Ожидается 83 / 100, Score 55.60722, один критический показатель.
5. Перед изменениями проверьте `git status` и договоритесь о файлах с другими участниками. Локальные новые возможности могут ещё отсутствовать на GitHub; после получения версии сверяйте её commit и состав.

## Границы

- Формула, данные и ограничения — из [DOCX](docs/brief-analysis/sources/dataset.txt); [PDF](docs/brief-analysis/sources/brief.txt) расходится с ним по числу направлений. Не объявляйте вопрос закрытым.
- Пять мер, стоимость и Score реально вычисляются; готовые пояснения не являются AI-вызовами.
- Поиск и экспорт другой интеграционной сборки не включены автоматически в эту панель.
- Мобильные приложения — отдельные локальные демо без веб-синхронизации; [маршруты](docs/user-guide/MOBILE.md).
- Сохраняйте чужие изменения, историю, [SOURCES](SOURCES.md) и [ORIGIN](demos/astana-story/ORIGIN.md). Публикация и merge требуют прямого разрешения.
- После изменения проверяйте затронутый путь и diff; не выдавайте тесты с подставными ответами за пруф живого AI.
