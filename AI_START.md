# Начать здесь — для команды и её ИИ

**Текущий интерфейс — АКИМ, `demos/astana-story/`, ветка `karim/simulator`.** Старый `demos/astana-city/` сохранён как предыдущий этап и источник ресурсов карты; он больше не основной пользовательский вход.

1. Прочитайте [README](README.md): запуск, реальные кнопки, пример из пяти направлений и ограничения.
2. Из корня репозитория запустите `node backend/server.mjs` (Node.js 24+).
3. Откройте [вход АКИМ](http://127.0.0.1:4197/) → «Открыть демонстрацию».
4. Проверьте собственный план: M1 Нура, M4 Сарыарка, M7 Нура, M10 Нура, M12 весь город. Ожидается 83 / 100, Score 55.60722, один критический показатель.
5. Перед изменениями проверьте `git status` и договоритесь о файлах с другими участниками. Локальные новые возможности могут ещё отсутствовать на GitHub; после получения версии сверяйте её commit и состав.

## Получить версию и передать правки команде

Если копии ещё нет, нужен GitHub-аккаунт с доступом к приватному репозиторию:

```sh
git clone --branch karim/simulator https://github.com/BAITC-Hacks/hack-ad91e510-samga-ai.git
cd hack-ad91e510-samga-ai
```

Если копия уже есть, сначала `git status` и сохранение собственных изменений. При чистом каталоге:

```sh
git fetch origin
git switch karim/simulator
git pull --ff-only origin karim/simulator
```

Если локальной ветки ещё нет: `git switch --track origin/karim/simulator`. Если истории разошлись, сохраните свои коммиты и согласуйте объединение; не применяйте force-push или сброс.

Для правки создайте собственную ветку `git switch -c your-name/task`, согласуйте файлы, проверьте результат и отправьте свою ветку после разрешения участника команды. Pull Request направляйте в `karim/simulator`; объединение в `main` и сдача на платформе — отдельный шаг. Совместного редактирования через страницу нет; общими изменения становятся через GitHub.

## Границы

- Формула, данные и ограничения — из [DOCX](docs/brief-analysis/sources/dataset.txt); [PDF](docs/brief-analysis/sources/brief.txt) расходится с ним по числу направлений. Не объявляйте вопрос закрытым.
- Пять мер, стоимость и Score реально вычисляются; готовые пояснения не являются AI-вызовами.
- Поиск и экспорт доступны через «Подбор и отчёт» и `/briefing/`; план сохраняется при переходах.
- Мобильные приложения включены в `mobile/`: отдельные локальные демо без веб-синхронизации; [запуск](mobile/README.md), просмотр скриншотов `/mobile/`.
- Сохраняйте чужие изменения, историю, [SOURCES](SOURCES.md) и [ORIGIN](demos/astana-story/ORIGIN.md). Публикация и merge требуют прямого разрешения.
- После изменения проверяйте затронутый путь и diff; не выдавайте тесты с подставными ответами за пруф живого AI.
