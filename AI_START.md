## Получить и увидеть результат

**Без Git:** [скачать готовый ZIP](https://github.com/BAITC-Hacks/hack-ad91e510-samga-ai/releases/download/astana-city-demo-v1/astana-city-demo.zip)
и следовать [START-HERE.md](START-HERE.md). Для быстрого просмотра достаточно
открыть `demos/astana-city/preview.png`. ZIP содержит код и запускается локально.
Скачать его могут участники с доступом к приватному репозиторию.

Если репозитория ещё нет:

```sh
git clone --branch demo/astana-city-base https://github.com/BAITC-Hacks/hack-ad91e510-samga-ai.git
cd hack-ad91e510-samga-ai
python3 start-demo.py
```

Браузер откроется автоматически; адрес со свободным портом появится в терминале.
На Windows вместо `python3` можно использовать `py`.
Репозиторий приватный: нужен GitHub-аккаунт с доступом команды. Сервер запускается
из корня репозитория. Нужен интернет для карты; ключи и зависимости ставить не нужно.
Ссылка `127.0.0.1` с чужого компьютера сама по себе макет не передаёт.

Если репозиторий уже клонирован, сначала проверьте `git status`, затем получите
ветку `demo/astana-city-base` через `git fetch origin` и переключитесь на неё
командой `git switch demo/astana-city-base`. Не сбрасывайте незакоммиченные
изменения и не переписывайте чужую историю. Если переключение блокируют свои
изменения, сначала сохраните их в собственной ветке.

## Текущее состояние интеграции

Ветка `feat/city-simulator-integration` объединяет утверждённую карту Карима
с `feat/verified-analytics`. Запуск: `node backend/server.mjs`, порт 3001.
Теперь работают выбор пяти проектов и районов, предпросмотр замены, ограничения,
сравнение сохранённого плана, все десять показателей, полный поиск стратегий,
разбор фактов и международные источники. Интерактивный слой добавлен в
`demos/astana-city/simulator.mjs` и `simulator.css`; карта остаётся в `app.mjs`.

Живой AI ожидает ключ команды; UI явно показывает это. До подключения доступны
все детерминированные инструменты. Горизонт только два года. У Сарайшыка нет
показателей. Расхождение PDF/DOCX о пяти направлениях остаётся открытым.
Старый релиз astana-city-demo-v1 — фиксированный макет, не новая интеграция.
Полный путь запуска и проверки: START-HERE.md.

## Как продолжать

- Сохранять выбранную композицию, цвета и карту; дорабатывать конкретную порученную часть.
- Использовать общую модель из `docs/brief-analysis/dist/model.mjs`, не создавать вторую формулу.
- Работать в своей ветке и согласовать файлы с командой, чтобы не перезаписывать параллельную работу.
- Новые зависимости, изменение архитектуры и отправку изменений согласовывать с участником,
  который ведёт свою ИИ-сессию. Не подключать сервисы только ради знакомства с макетом.
- После изменения проверить затронутый сценарий, синтаксис и применимые тесты;
  в отчёте отличать демонстрацию от реально подключённого AI.
