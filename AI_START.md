# Начать здесь — для команды и её ИИ

**Актуальный сайт: `demos/astana-story/`, ветка `karim/simulator`.**
Это панель «АКИМ» с гербом, восемью виджетами, картой, планами и сравнением,
которую Карим показывает на `127.0.0.1:8095/main.html#compare-widget`.
В репозитории путь длиннее, потому что рядом хранятся модель и другие материалы.
Ранняя ветка `demo/astana-city-base` содержит предыдущий макет.

## Первый запуск

Нужны Git, Python 3 и GitHub-аккаунт с доступом к приватному репозиторию команды.
Если репозитория ещё нет:

```sh
git clone --branch karim/simulator https://github.com/BAITC-Hacks/hack-ad91e510-samga-ai.git
cd hack-ad91e510-samga-ai
python3 -m http.server 8095 --bind 127.0.0.1
```

На Windows последняя команда: `py -m http.server 8095 --bind 127.0.0.1`.

- Вход: http://127.0.0.1:8095/demos/astana-story/.
- Панель: http://127.0.0.1:8095/demos/astana-story/main.html.
- Сравнение: http://127.0.0.1:8095/demos/astana-story/main.html#compare-widget.

Если порт занят, замените `8095` на `8096` в команде и адресе.
Сервер запускается **из корня репозитория**, не из папки демо.
Остановка — `Ctrl+C`. Нужен интернет для тайлов карты, npm и API-ключи не нужны.

Адрес `127.0.0.1` открывает сайт на вашем собственном компьютере.
Перемещение виджетов и тема сохраняются только в вашем браузере.
Изменения кода становятся общими после отправки в GitHub и получения командой;
совместного редактирования через страницу здесь нет.

## Если репозиторий уже есть

Сначала выполните `git status`. Если есть свои изменения, сохраните их в своей
ветке и сделайте коммит только нужных файлов. Не используйте сброс или очистку.
При чистом рабочем каталоге:

```sh
git fetch origin
git switch karim/simulator
git pull --ff-only origin karim/simulator
```

Если локальной ветки ещё нет: `git switch --track origin/karim/simulator`.
Если `pull --ff-only` сообщает о расхождении, сохраните свои коммиты и
согласуйте объединение с командой; не делайте force-push.

## Внести свою правку

От актуальной `karim/simulator` создайте отдельную ветку с вашим именем и задачей.
Пример, где `your-name` и `task` заменяются на свои значения:

```sh
git switch -c your-name/task
```

Согласуйте с командой, какие файлы меняете. Редактируйте исходники
`demos/astana-story/`, проверьте результат в браузере и выполните:

```sh
node --test docs/brief-analysis/test/model.test.mjs demos/astana-story/comparison.test.mjs
node --check demos/astana-story/app.mjs
```

Затем `git diff`, `git add` с явными путями изменённых файлов, содержательный
`git commit` и `git push -u origin your-name/task`. На GitHub создайте Pull Request
**в `karim/simulator`** и укажите, что изменилось и как проверено.
Отправка собственной ветки не меняет общую панель до объединения Pull Request.
Слияние в `main` и итоговая сдача согласуются отдельно.

## Где что менять

| Файл | Назначение |
|---|---|
| `demos/astana-story/main.html` | Состав панели и виджетов |
| `demos/astana-story/style.css`, `base.css` | Оформление панели и её основа |
| `demos/astana-story/app.mjs` | Сценарии, выбор районов, обновление виджетов |
| `demos/astana-story/comparison.mjs` | Подготовка планов и данных сравнения |
| `demos/astana-story/map.mjs` | Карта и связь с районами |
| `demos/astana-story/widget-layout.mjs` | Перемещение и сохранение раскладки |
| `demos/astana-story/index.html`, `login.css` | Входная страница |
| `docs/brief-analysis/dist/model.mjs`, `data.mjs` | Общая расчётная модель и датасет |

Не создавайте вторую формулу Score. `export-local.mjs` нужен только для
обновления отдельной локальной заготовки Карима; обычному участнику он не нужен.

## Что работает и что ещё нет

Работают вход в демонстрацию, обе темы, перемещение восьми виджетов,
пять этапов автоматического показа, три готовых плана, перенос районных мер,
пересчёт бюджета и Score, карта и сравнение вариантов.
Все показатели учебные. У Сарайшыка нет значений; не добавляйте вымышленные данные.

Свободный выбор любых пяти мер из M1–M14, живой AI-анализ и настоящая
авторизация в опубликованный срез не входят. Объяснения подготовлены заранее.
Расхождение PDF/DOCX о пяти направлениях остаётся открытым.

Команда планирует подключить OpenAI API позже. Ключ и хакатонный кредит пока не
используются. План серверной интеграции и границы точности: [API_INTEGRATION.md](docs/API_INTEGRATION.md).
