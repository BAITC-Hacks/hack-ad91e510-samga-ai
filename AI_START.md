## Получить и увидеть результат

Если репозитория ещё нет:

```sh
git clone https://github.com/BAITC-Hacks/hack-ad91e510-samga-ai.git
cd hack-ad91e510-samga-ai
python3 -m http.server 4195 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4195/demos/astana-city/.
На Windows вместо `python3` можно использовать `py`.
Репозиторий приватный: нужен GitHub-аккаунт с доступом команды. Сервер запускается
из корня репозитория. Нужен интернет для карты; ключи и зависимости ставить не нужно.
Ссылка `127.0.0.1` с чужого компьютера сама по себе макет не передаёт.

Если репозиторий уже клонирован, сначала проверьте `git status` и получите актуальную
`main`. Не сбрасывайте незакоммиченные изменения и не переписывайте чужую историю.

## Текущее состояние

Работают карта, районы, слои, камера и сравнение с фиксированным сценарием
`coverage`: пять решений, бюджет 85/100, индекс 52,6 → 55,7.
Все показатели учебные. У Сарайшыка нет значений; не добавляйте вымышленные данные.

До полного продукта остаются самостоятельный выбор пяти решений и районов,
контроль ограничений, реальный AI-анализ рассчитанного результата и полный
пользовательский сценарий. Это следующие работы, а не уже реализованные функции.
Расхождение PDF/DOCX о пяти направлениях остаётся открытым.

## Как продолжать

- Сохранять выбранную композицию, цвета и карту; дорабатывать конкретную порученную часть.
- Использовать общую модель из `docs/brief-analysis/dist/model.mjs`, не создавать вторую формулу.
- Работать в своей ветке и согласовать файлы с командой, чтобы не перезаписывать параллельную работу.
- Новые зависимости, изменение архитектуры и отправку изменений согласовывать с участником,
  который ведёт свою ИИ-сессию. Не подключать сервисы только ради знакомства с макетом.
- После изменения проверить затронутый сценарий, синтаксис и применимые тесты;
  в отчёте отличать демонстрацию от реально подключённого AI.
