# SAMGA AI · frontend Аслана

Самостоятельный мобильный frontend «Аким на 5 часов», ветка `aslan/frontend`.
Четыре связанных экрана: Сегодня, Решения, Районы, Итог. Работает без сборщика
на ES modules, HTML и CSS. Существующие `public/`, `server/` и расчётная модель
других участников не изменены.

## Быстрый запуск

Из корня репозитория, Node.js 24+:

```powershell
node frontend/dev-server.mjs
```

Открыть <http://127.0.0.1:4173>. Установка пакетов для самого приложения не нужна.
Порт меняется через `FRONTEND_PORT`. По умолчанию включён явно обозначенный
демо-режим. Он поддерживает произвольные допустимые сценарии: серверный адаптер
`services/demo-api.mjs` вызывает существующую командную модель, а браузер
получает готовые baseline и Score. Расчётная модель в браузер не загружается.
Демо-разбор содержит только факты из расчёта и не выдаётся за AI.

## Подключение backend команды

Запустите backend отдельно на его обычном порту, затем в другом терминале:

```powershell
$env:SAMGA_API_ORIGIN = 'http://127.0.0.1:3000'
node frontend/dev-server.mjs
```

Frontend-сервер передаёт `/api/*` backend через same-origin proxy, сохраняет
session cookies и заголовок `X-Samga-Request`. При запуске используется
`GET /api/me`; если сессии нет — `POST /api/auth/guest`.
Каталог берётся из командного `docs/brief-analysis/dist/data.mjs` через
`GET /catalog.json`. При выделении отдельного каталога backend замените этот
маршрут/метод в `services/api.mjs`.

Контракт:

- `/api/me`: `{ user, aiAvailable, baseline: { score, districts } }`.
- `POST /api/evaluate`: `{ choices: [{ id, district? }] }`, ответ — готовый
  `{ score, cost, districts: [{ name, pop, score, values, profile }], ... }`.
- `POST /api/analyze`: тот же запрос; ответ содержит `mode`, `explanation`,
  `notice`, `summary: [{ text }]`, `recommendations: [{ title, description }]`.

Ключи AI хранятся только на backend. При отсутствии ключа интерфейс явно
показывает расчётный разбор. Сетевые ошибки не заменяются выдуманным результатом;
анализ можно повторить отдельно от расчёта.

## Структура

```text
components/  GlassCard, GlassTabBar, ScoreRing, BudgetHeader, DecisionCard,
             DistrictSheet, DistrictCard, MetricBar, AIInsightCard, Icon
screens/     Home, Decisions, Districts, Result
services/    API-клиент и отдельный серверный demo-адаптер
lib/         ограничения, восстановление черновика, форматирование, анимации
test/        сценарии, HTTP-контракт, браузерный пользовательский путь
```

Выбор сохраняется в localStorage; повреждённые данные восстанавливаются безопасно.
Изменение любого решения сбрасывает старые результаты и делает неактуальные
AI-ответы недействительными. Районы показывают долю населения, потому что
абсолютной численности в исходном датасете нет. Средние показатели направлений
используются для визуализации, не для вычисления Quality of Life Score.

## Проверки

```powershell
node --test frontend/test/*.test.mjs docs/brief-analysis/test/model.test.mjs
```

Браузерные проверки требуют Playwright и Chrome/Edge:

```powershell
cd frontend
npm.cmd install
npm.cmd run test:browser
```

На Windows автоматически находится установленный Chrome или Edge. В других
системах: `npx playwright install chromium` или переменная `BROWSER_PATH`.
Тест поднимает отдельный сервер на свободном порту и проверяет экраны при
ширинах 1440, 390 и 320 px, выбор пяти мер, восстановление черновика,
доступность диалога с клавиатуры, расчёт, отсутствие переполнения и защиту
от устаревших ответов AI. Скриншоты сохраняются в игнорируемую `test-results/`.
Для проверки того же пути через запущенный backend задайте
`$env:TEST_API_ORIGIN = 'http://127.0.0.1:3000'` перед `npm.cmd run test:browser`.

Для воспроизводимой демонстрации выберите: школа и поликлиника в Нуре,
освещение и камеры в Нуре, цифровая платформа обращений, чистое топливо
в Сарыарке. Стоимость — 95, серверный Score — 56.54307 (на экране 56,54),
прирост — 3.98539 (на экране +3,99). Пример не является заявлением об оптимуме.

Анимации короткие; `prefers-reduced-motion`, safe area и управление с клавиатуры
учтены. Haptic feedback использует `navigator.vibrate` там, где браузер его
поддерживает. Проверка выполнена в Chromium; реальное устройство iOS отдельно
не тестировалось.

Реализация подготовлена Асланом с помощью Codex. Источник данных и формулы —
существующие командные файлы `docs/brief-analysis/dist/`; новые изображения,
внешние шрифты и библиотеки интерфейса не использованы.
