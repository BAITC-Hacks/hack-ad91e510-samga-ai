# SAMGA · Аким на 5 часов

Пошаговый симулятор городских решений, frontend Аслана, ветка `aslan/frontend`.
Первый экран объясняет роль акима, бюджет 100 единиц и задачу принять пять решений.
Пользователь выбирает проблему района, сравнивает меры по цене, эффекту и срокам,
получает подтверждение выбора, а после пяти решений — результат и его объяснение.
Карта стала отдельным инструментом. Основные разделы: Начало, Управление,
Карта, Итог; каталог и аналитика районов доступны дополнительно.
ES modules, HTML и CSS, без сборщика.
Существующие `public/`, `server/` и расчётная модель других участников не изменены.

## Основной пользовательский путь

`#home` → «Начать управление» → `#play` → проблема → варианты мер →
подтверждение решения → следующий приоритет → проверка плана → `#result`.

- Бюджет и прогресс 0–5 видны на каждом шаге, черновик сохраняется.
- Подбор проблем основан на исходных показателях; запланированная мера
  не выдаётся за фактически выполненное улучшение.
- Guided-режим проверяет, можно ли после выбранной меры завершить допустимый
  план из пяти решений. Это проверка ограничений, не расчёт/оптимизация Score.
- Если ранее составленный свободный план оставил слишком маленький бюджет,
  интерфейс предлагает убрать один пункт и выбрать другую меру.
- Итог объясняет, сколько районов получили улучшение, где изменение сильнее
  всего и какой показатель остаётся самым низким. Все числа взяты из ответа
  сервера и baseline, а не придуманы интерфейсом.
- `#map`, `#decisions` и `#districts` доступны как инструменты исследования.
  На стартовом экране WebGL не запускается.

## Работа с картой

В разделе «Карта» по умолчанию открывается настоящая 3D-сцена. Нажатие на район приближает
городской фрагмент с объёмными зданиями, нажатие на здание — открывает его
карточку. Левой кнопкой мыши/одним пальцем можно вращать сцену, правой кнопкой —
перемещать, колесом/жестом двух пальцев — менять масштаб. Есть переключатель
зданий, наклона, полноэкранный режим и кнопка возврата к городу.
Стрелки управляют камерой с клавиатуры, Enter приближает выбранный район,
Escape закрывает карточку/возвращает обзор. Камера сохраняется при выборе
показателей и мер, WebGL-контекст не пересоздаётся после каждого действия.

Переключатель **3D / 2D** возвращает прежнюю SVG-карту. При отсутствии WebGL
или потере графического контекста 2D включается автоматически. Для прямого
открытия 2D используйте `/?map=2d#map`.

1. Выберите полигон, метку или название района под картой.
2. Выберите направление и проблемный показатель справа.
3. Добавьте подходящую меру в план: район уже выбран. Городские меры
   применяются ко всему городу. Назначение, стоимость и эффект видны до выбора.
4. Соберите ровно пять совместимых решений на сумму до 100 единиц и нажмите
   «Рассчитать последствия» в блоке плана.
5. Вернитесь на карту: переключатель «До решений / После» сравнивает исходные
   показатели с результатом сервера. Изменение плана отменяет старый результат.

В режиме 2D карта поддерживает перетаскивание, кнопки масштаба и сброса, Ctrl + колесо мыши,
выбор района клавишами Enter/Пробел. Панель справа связывает показатель только
с мерами, которые имеют положительный эффект именно на него. Порядок мер — по
полному эффекту на выбранный показатель, затем стоимости; это не оптимизатор.

Контуры районов, дороги, река и парки — реальная география OpenStreetMap,
встроенная в проект, без внешних тайлов и сетевых запросов при использовании.
Срез источника — 31.05.2026. Подсветка и объём — оформление, не высоты рельефа.
Показатели и «проблемы» — условные данные модели, не реальные обращения жителей.
Пять районов сохранены по датасету, актуальная Астана имеет шесть районов.
Происхождение, лицензия ODbL и воспроизводимая подготовка карты — [MAP-SOURCES.md](MAP-SOURCES.md).
Добавлены 4 032 контура зданий в пяти городских фрагментах. Высоты частично
известны из OSM, частично оценочные; происхождение показано в карточке здания.
Это интерактивный макет застройки, без интерьеров и полного покрытия города.
Three.js поставляется локально с лицензией MIT — [THIRD-PARTY.md](THIRD-PARTY.md).

## Быстрый запуск

Из корня репозитория, Node.js 24+:

```powershell
node frontend/dev-server.mjs
```

Открыть <http://127.0.0.1:4173>. Установка пакетов для самого приложения не нужна.
Порт меняется через `FRONTEND_PORT`. По умолчанию включён явно обозначенный
демо-режим. Он поддерживает произвольные допустимые сценарии: серверный адаптер
`services/demo-api.mjs` вызывает существующую командную модель, а браузер
получает готовые baseline и Score. Расчётная модель в браузер не загружается.
Демо-разбор содержит только факты из расчёта и не выдаётся за AI.

## Подключение backend команды

Запустите backend отдельно на его обычном порту, затем в другом терминале:

```powershell
$env:SAMGA_API_ORIGIN = 'http://127.0.0.1:3000'
node frontend/dev-server.mjs
```

Frontend-сервер передаёт `/api/*` backend через same-origin proxy, сохраняет
session cookies и заголовок `X-Samga-Request`. При запуске используется
`GET /api/me`; если сессии нет — `POST /api/auth/guest`.
Каталог берётся из командного `docs/brief-analysis/dist/data.mjs` через
`GET /catalog.json`. При выделении отдельного каталога backend замените этот
маршрут/метод в `services/api.mjs`.

Контракт:

- `/api/me`: `{ user, aiAvailable, baseline: { score, districts } }`.
- `POST /api/evaluate`: `{ choices: [{ id, district? }] }`, ответ — готовый
  `{ score, cost, districts: [{ name, pop, score, values, profile }], ... }`.
- `POST /api/analyze`: тот же запрос; ответ содержит `mode`, `explanation`,
  `notice`, `summary: [{ text }]`, `recommendations: [{ title, description }]`.

Ключи AI хранятся только на backend. При отсутствии ключа интерфейс явно
показывает расчётный разбор. Сетевые ошибки не заменяются выдуманным результатом;
анализ можно повторить отдельно от расчёта.

## Структура

```text
components/  JourneyProgress, PlanSummary, OutcomeSummary,
             ControlShell, CityMap, DistrictInspector, ScenarioDock,
             GlassCard, GlassTabBar, ScoreRing, BudgetHeader, DecisionCard,
             DistrictSheet, DistrictCard, MetricBar, AIInsightCard, Icon
screens/     Welcome, Manage, Dashboard, Decisions, Districts, Result
             (Home — предыдущий экран, сохранён как исходная реализация)
services/    API-клиент и отдельный серверный demo-адаптер
lib/         пользовательский сценарий, география, проблемы районов, управление картой, ограничения,
             восстановление черновика, форматирование, анимации
data/        геометрия и исходные сведения о зданиях
vendor/      зафиксированные локальные модули Three.js и MIT-лицензия
scripts/     воспроизводимая подготовка данных OpenStreetMap
test/        сценарии, HTTP-контракт, карта, браузерные пользовательские пути
```

Выбор сохраняется в localStorage; повреждённые данные восстанавливаются безопасно.
Изменение любого решения сбрасывает старые результаты и делает неактуальные
AI-ответы недействительными. Районы показывают долю населения, потому что
абсолютной численности в исходном датасете нет. Средние показатели направлений
используются для визуализации, не для вычисления Quality of Life Score.

## Проверки

```powershell
node --test frontend/test/*.test.mjs docs/brief-analysis/test/model.test.mjs
```

Браузерные проверки требуют Playwright и Chrome/Edge:

```powershell
cd frontend
npm.cmd install
npm.cmd run test:browser
```

На Windows автоматически находится установленный Chrome или Edge. В других
системах: `npx playwright install chromium` или переменная `BROWSER_PATH`.
Тесты поднимают отдельные серверы на свободных портах и проверяют экраны при
ширинах 1600, 1440, 1024, 768, 390 и 320 px, выбор пяти мер прямо на карте,
переключение районов/слоёв, масштаб, «До / После», восстановление черновика,
доступность диалога с клавиатуры, расчёт, отсутствие переполнения и защиту
от устаревших ответов AI. Скриншоты сохраняются в игнорируемую `test-results/`.
Отдельный браузерный сценарий проверяет настоящую WebGL-сцену: приближение,
вращение, выбор здания, сохранение контекста, полноэкранное переключение
районов, клавиатуру и восстановление после потери GPU-контекста. Для
воспроизводимости headless-тест использует программный WebGL; обычный браузер
выбирает доступный графический ускоритель самостоятельно.
Для проверки того же пути через запущенный backend задайте
`$env:TEST_API_ORIGIN = 'http://127.0.0.1:3000'` перед `npm.cmd run test:browser`.

Для воспроизводимой демонстрации выберите: школа и поликлиника в Нуре,
освещение и камеры в Нуре, цифровая платформа обращений, чистое топливо
в Сарыарке. Стоимость — 95, серверный Score — 56.54307 (на экране 56,54),
прирост — 3.98539 (на экране +3,99). Пример не является заявлением об оптимуме.

Анимации короткие; `prefers-reduced-motion`, safe area и управление с клавиатуры
учтены. Haptic feedback использует `navigator.vibrate` там, где браузер его
поддерживает. Проверка выполнена в Chromium; реальное устройство iOS отдельно
не тестировалось.

Реализация подготовлена Асланом с помощью Codex. Источник данных и формулы —
существующие командные файлы `docs/brief-analysis/dist/`; карта использует
OpenStreetMap с атрибуцией. Внешние шрифты не используются. Three.js применяется
для отрисовки сцены и не отправляет данные на внешние сервисы.
