В файле `lib/astana-geography.mjs` — производная географическая база под ODbL:
замкнутые внешние контуры районов, 2284 участка магистральных дорог,
386 водных объектов/участков русел и 135 парков. Геометрия упрощена для
отрисовки; применяется локальная косоугольная проекция для объёмного вида.
Точки названий находятся внутри соответствующих исходных полигонов.
Объём, подсветка и сетка — оформление интерфейса, не данные о высоте местности.

Исходный запрос полностью приведён в `scripts/fetch-map.mjs`.
`scripts/build-map.mjs` соединяет сегменты границ, проверяет замыкание и
положение подписей, упрощает линии и создаёт встроенный модуль геометрии.
Для воспроизведения из корня репозитория:

```powershell
node frontend/scripts/fetch-map.mjs
node frontend/scripts/build-map.mjs
```

Первый шаг требует сети; приложение после подготовки геометрии — нет.
Сырые данные сохраняются в игнорируемую папку `frontend/test-results/`.

По [сведениям акимата](https://www.gov.kz/memleket/entities/astana-saulet/press/news/details/1274528)
Астана имеет шесть административных районов, включая Сарайшық. Симулятор
сохраняет пять районов предоставленного командой датасета. Контуры этого
среза OSM не выдаются за актуальную кадастровую карту.

Показатели, проблемы, население и эффекты мер **не получены из OpenStreetMap**.
Это условные данные командного симулятора. Метки обозначают район в целом,
а не точные адреса происшествий. Порог внимания 60 — правило отображения
дашборда; критический порог 40 соответствует модели. Изменения после решений
отображаются только после серверного расчёта.

## Настоящая 3D-сцена и здания

Режим 3D использует WebGL/Three.js. Косоугольная проекция старой SVG-карты
обращается в географические координаты, после чего создаётся сцена с камерой.
Толщина платформ районов — оформление, не реальная высота рельефа.

`data/astana-buildings.json` содержит **4 032 контура зданий** в пяти городских
фрагментах. Дата начала среза Overpass: **2026-09-23T11:14:53Z**. Это не полное
покрытие Астаны и не фотограмметрическая модель. Дата контуров районов остаётся
31.05.2026; геометрия районов сохраняет пять территорий командной модели.

| Район модели | Зданий в фрагментах |
| --- | ---: |
| Есиль | 486 |
| Алматы | 918 |
| Сарыарка | 1 385 |
| Байконур | 961 |
| Нура | 282 |

Высота из тега OSM `height` доступна для 13 зданий. Для 2 112 объектов высота
оценивается по `building:levels × 3 м`. У 1 907 объектов данных нет, им назначена
**условная** высота 9 м. Это различие показано в карточке выбранного здания.
Для читаемости вертикальный масштаб застройки в сцене увеличен в 2,5 раза;
число метров в карточке остаётся исходным/оценочным, с соответствующей подписью.
Точные формы крыш, фасады, этажи внутри и интерьеры не моделируются.

Клик по зданию показывает только его OSM-данные. Районные проблемы не
приписываются конкретным зданиям. Мероприятия применяются к району/городу
через прежнюю расчётную модель; дата и фактическое выполнение строительства
не выдумываются.

Воспроизводимая подготовка:

```powershell
node frontend/scripts/fetch-buildings.mjs
node frontend/scripts/build-buildings.mjs
```

Первый скрипт использует небольшие запросы по пяти областям, кэширует успешные
фрагменты и ждёт при ограничении запросов сервера. Границы областей записаны
в скрипте и выходном JSON. Второй проверяет замкнутость контуров, принадлежность
району, единицы и происхождение высот. Производная база остаётся под ODbL.
