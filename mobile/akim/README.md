# АКИМ для iPhone

## Расширенная демоверсия

Последняя сборка для симулятора: `Delivery/AKIM.app` (BUILD SUCCEEDED).
Финальное повторное открытие заблокировано общим сбоем Xcode27/CoreSimulator:
зависают launch/screenshot, XCTest не начал runtime. До сбоя четыре раздела
проверены вручную. Автоматический тест не отмечен прошедшим.

После «Открыть демоверсию» доступны четыре нативные вкладки:

- **События:** шесть городских историй, фильтры, фото, детали и локальное взятие на контроль.
- **Карта:** Apple Maps с пятью условными объектами, фильтрами, списком и карточками.
- **Чаты:** пять рабочих комнат, сообщения, локальная отправка и вложенный план работ.
- **Помощник:** четыре готовых примера — утренняя сводка, поручение, ответ жителю,
  концепция двора; сохранение в черновики текущего сеанса.

Все истории, цифры, переписки и статусы вымышлены. Чат и ответы помощника работают
локально, реальная AI-модель и сервер обмена сообщениями не подключены.
Карточки новостей используют две новые сгенерированные иллюстрации;
[промпты и происхождение](Resources/demo-image-sources.md).

Исходники разделов: `DemoFeedView.swift`, `DemoMapView.swift`, `DemoChatsView.swift`,
`DemoAssistantView.swift`; навигация — `DemoRootView.swift`.
Для выхода ко входу: меню «АКИМ» вверху ленты → «Вернуться ко входу».

Самостоятельное приложение SwiftUI: иконка с гербом, нативная форма входа
и демонстрационный кабинет. В приложении нет Safari, WKWebView или подключения
к локальному сайту. Иллюстрации и демоданные включены в сборку.
Подложка Apple Maps требует интернет; геопозиция пользователя не запрашивается.

Вход переработан под iPhone: цельный системный фон, герб и название, форма
без внешней карточки, основное действие внизу. Фотофон и веб-футер убраны.

`AKIM.xcodeproj` — проект для открытия в Xcode. `project.yml` — воспроизводимое
описание проекта для уже установленного XcodeGen. Внешних библиотек нет.

## Сборка и запуск в используемом симуляторе

```sh
xcodegen generate --spec project.yml
xcodebuild -project AKIM.xcodeproj -scheme AKIM -configuration Debug \
  -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,id=AE8443B5-4E81-443C-9C92-C7AC94672F87' \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
xcrun simctl install AE8443B5-4E81-443C-9C92-C7AC94672F87 \
  build/Build/Products/Debug-iphonesimulator/AKIM.app
xcrun simctl launch AE8443B5-4E81-443C-9C92-C7AC94672F87 kz.hackalem.akim
```

Bundle ID: `kz.hackalem.akim`. На домашнем экране: **АКИМ**.
Для показа сразу с ленты передайте `--demo` после bundle ID в `simctl launch`.
На физическом iPhone понадобится подпись Apple Developer/Personal Team в Xcode;
текущая сборка предназначена для симулятора.

## Ресурсы

- `KazakhstanEmblem` — присланный герб, преобразован из WebP в PNG без перерисовки.
- `CivicHall` — сохранённый ресурс предыдущей версии; текущий вход его не использует.
- `AppIcon` — тот же герб на синем фоне, PNG 1024×1024. Воспроизводимая сборка
  ресурса: `xcrun swift Tools/make-app-icon.swift` из папки проекта.
- Происхождение фона и промпт: `../Сайт/assets/akim-image-source.md`.

## Границы демоверсии

Форма ничего не отправляет, пароли не сохраняются. Настоящая авторизация
не подключена. Расширенный кабинет содержит обозначенные демонстрационные сценарии.
В настройках сохраняется только выбранная тема; сообщения и черновики живут в памяти сеанса.
