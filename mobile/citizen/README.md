# АКИМ Житель — локальная демоверсия iPhone

Самостоятельное SwiftUI-приложение для показа гражданского сценария. Основной проект `../заготовки/АКИМ-iOS` и его симулятор не менялись.

## Быстрый показ

1. **Мой район → Фото / Голос / Текст.** Все способы открывают единый блок ввода, как в Sardar102. Текст необязателен при наличии вложения.
2. **Посмотреть пример** — готовый учебный сценарий с фото и описанием, явно подписанный как заранее подготовленный.
3. **Продолжить → проверить адрес → Отправить в демо.** Появляется номер и ссылка на обращение.
4. **Открыть обращение → Демо: показать следующий этап.** Пройти получение, рассмотрение, план, работу и отчёт. Затем подтвердить или вернуть в работу.
5. **Мои обращения** сохраняет обращения после перезапуска; **Слежу** содержит подписанные карточки. **Карта** показывает только учебные точки с известной геометрией. Новые адреса не выдаются за геокодированные координаты.

## Фото, голос и ИИ

- Системная камера доступна на физическом iPhone; симулятор предлагает галерею или учебный пример.
- Голос записывается локально в M4A (до 2 минут), воспроизводится и сохраняется вместе с обращением. Предусмотрена ошибка отказа в доступе к микрофону.
- Реальный разбор: **Профиль → Подключение ИИ**. Ключ OpenAI вводится самим пользователем и живёт только в памяти процесса. В файлы, сборку и логи ключ не записывается.
- **Разобрать с ИИ** отправляет выбранные материалы в OpenAI: Responses / `gpt-4.1-mini` для изображения и текста; Audio Transcriptions / `gpt-4o-mini-transcribe` для речи. Произвольная фотография никогда не обрабатывается локальным шаблоном под видом ИИ.
- Если ключ не введён или запрос не удался, материалы остаются доступны и их можно сохранить без анализа. AI-текст редактируется перед отправкой; модель не должна выдумывать адреса, дефекты и сроки.
- Это сессионное подключение для личного локального демо. Перед распространением вынести API на авторизованный сервер, не раздавать приложение с общим ключом. Ключей в текущей сборке нет.
- API-контракт сверялся с официальной документацией: [Images and vision](https://developers.openai.com/api/docs/guides/images-vision), [File transcription](https://developers.openai.com/api/docs/guides/speech-to-text). Живые запросы без пользовательского ключа не проверены.

## Перенос в основной АКИМ

После завершения работы владельца основного приложения переносить только `Core/`, `Sources/` без `CitizenApp` entrypoint и `Resources/Assets.xcassets/` с разрешением конфликтов ресурсов. Точка встраивания — `CitizenRootView().environmentObject(CitizenStore())`. Store должен жить у корня, а не создаваться на каждом показе. Нужны privacy descriptions микрофона и камеры из `project.yml`.

Главный АКИМ, API/контракты, shared/astana-demo, ассистент другого чата и его сервис не изменены. Никакой публикации или push не выполнялось.

## Что является демо

Все городские карточки, адреса, сроки и поддержки синтетические. CityRoad/CityPark — художественные иллюстрации из исходного АКИМ, не реальные фото работ. Исполнение и официальная подача в городские службы не подключены. На карте нужны данные Apple Maps и сеть; карточки и обращения доступны без сети.
