# ASTANA / City Lab — выбранный макет команды

23.09.2026 Карим выбрал этот интерфейс за основу дальнейшей доработки
«Аким на 5 часов». Перенесён из локального `заготовки/astana-city-demo`;
изменены только пути к общей модели и геометрии, внешний вид и поведение сохранены.

## Запуск

Самый простой способ: распаковать командный ZIP и открыть `START-WINDOWS.bat`
или `START-MAC.command` в его корне. Нужен Python 3; подробности в
[START-HERE.md](../../START-HERE.md). Универсальная команда: `python3 start-demo.py`.
Браузер открывается автоматически, порт выбирается свободный.

Ручной вариант:

Из **корня репозитория**, а не из этой папки:

```sh
python3 -m http.server 4195 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4195/demos/astana-city/.
Windows: `py -m http.server 4195 --bind 127.0.0.1`.
Нужны Python 3, браузер с WebGL и интернет для тайлов, подписей и спрайтов
OpenFreeMap. Ключи и установка npm/pip-пакетов не нужны. Через `file://` не работает.
`127.0.0.1` всегда означает компьютер того, кто открывает ссылку: сначала
получите весь репозиторий и запустите сервер у себя.

## Что уже работает

- Объёмная карта Астаны, масштабирование, 2D/3D и возврат к центру.
- Выбор района списком и на карте, слои города, районов и парков.
- Пять фиксированных решений сценария `coverage`, стоимость 85 из 100.
- Сравнение исходного состояния и результата: индекс 52,6 → 55,7.
- Синтетические показатели из общей модели `../../docs/brief-analysis/dist/`.

Самостоятельный выбор мер и районов для плана, backend и живой AI-анализ
ещё не реализованы. Подписи ориентиров не являются отдельными 3D-моделями;
здания — экструзия контуров, высоты могут быть оценочными.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Разметка экрана и элементы управления |
| `style.css` | Визуальный стиль и адаптивная вёрстка |
| `app.mjs` | Карта, выбор района, слои, отображение двух состояний |
| `base-style.json` | Базовый стиль OpenFreeMap и адреса картографических ресурсов |

| `vendor/` | MapLibre GL JS 5.6.2, CSS и лицензия |
| `preview.png`, `districts-preview.png`, `mobile-preview.png` | Изображения исходного макета для знакомства с дизайном |

Формула, данные и сценарии не дублируются: они импортируются из `docs/brief-analysis/dist/`.
Поэтому передавайте весь репозиторий, а не только эту папку.

## Быстрая проверка

1. Открыть страницу: видны здания, начальный индекс 52,6 и бюджет 85/100.
2. Нажать «Показать результат»: индекс становится 55,7; вернуться к исходному.
3. Выбрать Нуру и слой «Районы»: меняются карточка, положение камеры и границы.
4. Выбрать Сарайшық: вместо придуманных показателей отображается отсутствие данных.

Из корня репозитория:

```sh
node --check demos/astana-city/app.mjs
node --test docs/brief-analysis/test/model.test.mjs
```

## Происхождение и ограничения

Карта: OpenFreeMap / OpenMapTiles / OpenStreetMap; атрибуция сохранена в интерфейсе.
Стиль взят из [OpenFreeMap dark](https://tiles.openfreemap.org/styles/dark),
объёмные здания используют MapLibre. Лицензия библиотеки — [vendor/LICENSE.txt](vendor/LICENSE.txt).
Контуры извлечены из ранее подготовленной карты ARLAN; актуальность после
административных изменений не проверена. Сарайшық не имеет значений в датасете
и не включается в расчёт. Перелёт ведёт к приблизительной обзорной точке района.
Показатели учебные и не являются городской статистикой.
Подробности — [SOURCES.md](../../SOURCES.md), контекст доработки — [AI_START.md](../../AI_START.md).
