# ASTANA / City Lab — основной интерфейс SAMGA AI

Выбранная командой карта дополнена самостоятельным выбором пяти мер,
серверным расчётом и отдельным AI-объяснением.

Из корня репозитория: `node backend/server.mjs`.
Открыть http://127.0.0.1:4197/. Нужен Node.js 24+, без npm install.
Отдельный статический сервер Python не предоставляет API продукта.

- Начальное состояние: пустой план, бюджет 100, пять районов из DOCX.
- Каталог: 14 мер; выбор района обязателен для районных мер.
- Расчёт: ровно пять уникальных решений с проверкой бюджета/несовместимостей.
- Результат: Score, все районы, десять показателей, синергии и переключение карты.
- AI: живой режим только после настройки командного OpenAI; demo явно «Без LLM».
- Сарайшык: отображается на карте без выдуманных конкурсных показателей.

География OpenStreetMap/OpenFreeMap, локальная MapLibre GL JS 5.6.2.
Для внешних тайлов нужен интернет и WebGL; расчёт от них не зависит.
Внешний sprite может выдавать предупреждение wood-pattern; это не ошибка engine.
Сохранённые preview.png/result.png показывают исходную выбранную визуальную основу,
а не пруф текущей интеграции.
