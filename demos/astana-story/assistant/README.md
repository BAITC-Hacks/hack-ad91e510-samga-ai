# Ассистент АКИМ

Плавающая кнопка открывает чат с 3D-головой. GPT получает текущий план и рассчитанные сервером показатели; текст появляется по мере генерации. Под ответом — сравнение трёх вариантов и действия для панели. ElevenLabs озвучивает ответ и распознаёт записанный вопрос. Перед отправкой голосового вопроса пользователь проверяет распознанный текст.

## Локальный запуск

Из корня репозитория:

```sh
node assistant-service/server.mjs
```

Откройте существующую панель на `http://127.0.0.1:8095/main.html`, нажмите круглую кнопку справа снизу → настройки → введите ключи OpenAI и ElevenLabs. Они передаются только локальному API и хранятся в памяти процесса до его остановки. Браузер их не сохраняет. После настройки вернитесь к чату; для озвучивания включите звук.

Доступность ключей означает только настройку. Реальный доступ к провайдерам подтверждается успешным ответом/аудио. При ошибке нет подмены ответа шаблоном или системным синтезом речи.

## Данные и действия

- Числа берутся из существующего simulation engine, а не вычисляются GPT. Для неполного плана итоговый балл отсутствует.
- Кнопки результата вызывают только три разрешённых действия: показать сравнение, показать район, выбрать существующий сценарий. До клика план не меняется.
- Если план изменился после вопроса, старое действие блокируется до нового запроса.
- Закрытие панели отменяет запросы, звук и запись, освобождает WebGL-сцену.
- Модуль подключается через `assistant-bootstrap.mjs`; `export-local.mjs` переносит его рядом с существующим входом АКИМ.

Источник визуального образа и локальная модель описаны в [avatar/ORIGIN.md](avatar/ORIGIN.md). Данные и серверные компоненты SARDAR не переносятся.

Проверки из корня: `node --test assistant-service/test/*.test.mjs demos/astana-story/assistant/sse.test.mjs`. HTTP-тесты используют управляемые ответы провайдеров; они не подтверждают доступ ключей, качество голоса или задержку живого API.
