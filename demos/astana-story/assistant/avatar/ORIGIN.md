# Происхождение 3D-головы

Это локальный, неопубликованный перенос визуального референса SARDAR для прототипа AKIM.
Модель `assets/avatarsdk.glb` скопирована из
`/Users/karim/Documents/SARDAR/apps/web-sardar/frontend/public/sardar-ai/heads/avatarsdk.glb`.
Она содержит геометрию AvatarSDK; отдельная лицензия модели в исходном каталоге не найдена.
До размещения в публичном репозитории или публикации нужно подтвердить право распространения.
Служебные данные, код API и конфигурация SARDAR сюда не переносились.

Локальная копия Three.js 0.183.2 (`vendor/`) взята из уже установленного
`web-sardar/node_modules/three`. Лицензия библиотеки: `vendor/LICENSE` (MIT).
`GLTFLoader.js` и его две утилиты используют только локальный `three.module.js`;
новые пакеты и сетевые ресурсы не требуются.

`head.mjs` воспроизводит визуальные принципы исходного виджета: ту же GLB-модель,
сине-бирюзовый голографический материал, лёгкий поворот и лазерную сборку
с задержкой 1 с и проходом 7 с. Это отдельная реализация на чистом Three.js,
без копирования React, серверной логики и голосовых функций SARDAR.
