# ASTANA — демонстрация пяти решений

Отдельный сценарный макет на основе `../astana-city/`. Показывает путь от бюджета 100 через пять решений и запуск проектов к результату через 8 кварталов. Исходный макет не изменён.

## Открыть

Из корня репозитория:

```sh
python3 -m http.server 4196 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4196/demos/astana-story/ . Если сервер уже запущен на этом порту, достаточно открыть адрес.

Нажмите **«Смотреть демо»**: показ занимает около минуты. Можно поставить его на паузу, пройти шаги кнопками вперёд/назад, выбрать шаг в нижней полосе и начать заново. При уходе со вкладки показ ставится на паузу.

## Что демонстрируется

1. Исходные проблемы Нуры и Сарыарки, бюджет 100.
2. Фиксированный план `coverage`: M1 Нура → M4 Сарыарка → M7 Нура → M10 Нура → M14 город.
3. Накопленные расходы: 18 → 33 → 57 → 69 → 85. Остаток 15.
4. Все проекты запускаются вместе. Восемь кварталов показывают ожидание и начало эффекта с учётом лага. Промежуточный городской индекс не рассчитывается и не показывается как новый результат.
5. Финальный индекс: 52.55768 → 55.70806, рост 3.15038. Критических показателей становится 1 вместо 2. Медицина Нуры остаётся на 35.

Все конечные показатели поступают из общей модели `../../docs/brief-analysis/dist/model.mjs`; `demo-state.mjs` управляет только шагами показа. Пояснение подготовлено заранее, живого обращения к LLM нет. Это фиксированный демонстрационный план, а не свободный выбор из 14 мер.

## Карта и границы демонстрации

MapLibre, стиль и геометрия используются из `../astana-city/`, библиотеки не установлены повторно. Нужен интернет для тайлов OpenFreeMap. При ошибке карты сценарий и показатели остаются доступны. Атрибуция OpenStreetMap/OpenMapTiles/OpenFreeMap сохранена.

Метки проектов размещены условно для рассказа и не обозначают реальные участки. «Работы идут» / «Даёт эффект» иллюстрируют лаг мер. Здания карты не являются моделями новых строек. Данные учебные. География может содержать шестой район, но расчёт использует только пять районов датасета.

## Проверки

```sh
node --test docs/brief-analysis/test/model.test.mjs demos/astana-story/demo-state.test.mjs
node --check demos/astana-story/app.mjs
node --check demos/astana-story/map.mjs
```

Браузерная приёмка на компьютере: пять решений → проверка плана → кварталы 1–8 → результат; сравнение с началом; повтор; автопоказ и пауза. Отдельная мобильная доработка отложена по запросу Карима.
