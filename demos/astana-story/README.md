# ASTANA — сравнение решений для города

Демонстрационный макет для компьютера. Объясняет, как при одинаковом бюджете разные получатели помощи меняют итог города. Адрес сохранён: http://127.0.0.1:4196/demos/astana-story/ .

## Посмотреть

Из корня репозитория, если сервер ещё не запущен:

```sh
python3 -m http.server 4196 --bind 127.0.0.1
```

Кнопка **«Смотреть разбор»** показывает пять этапов за 44 секунды: исходные проблемы → неудачный приоритет → исправленное распределение → экономия → итог. Есть пауза, шаг назад, ручной переход и возврат к началу. Можно сразу выбрать любой план внизу.

## Три варианта

| План | Расходы | Score | Показателей ниже 40 |
|---|---:|---:|---:|
| Все районные меры — в Есиль | 95 | 53.8565475 | 2 |
| Помочь слабым районам | 95 | 56.54307 | 0 |
| Сохранить резерв | 61 | 55.343025 | 1 |

Исходный Score: 52.55768. Первые два набора содержат одинаковые меры M7/M8/M10/M12/M5. Отличаются районы назначения. В обоих вариантах M12 действует для всего города.

В первом плане показатели школ и медицины Нуры остаются 38 и 35. Во втором — становятся 48 и 43.75. При экономии медицина Нуры остаётся на 37.625; разгрузка дорог снижается с 55 до 53.25 из-за M11. Противоположный положительный эффект этой меры — безопасность движения.

«Лучший из трёх» означает только наибольший Score среди показанных пресетов. Глобальная оптимальность не заявляется. Нулевой штраф не означает, что все потребности удовлетворены.

## Что можно проверить самому

- Выбрать район на карте или в списке справа и увидеть исходные/итоговые показатели.
- Переключить «Сейчас» / «Через 2 года».
- Раскрыть «На что идут деньги» и поменять район любого районного проекта.
- Например: в плане «Всё в Есиль» перенести школу в Нуру. Расходы останутся 95, школы Нуры вырастут 38 → 48, критических показателей станет 1 вместо 2.
- Результат собственного варианта показывается справа и в закреплённой строке редактора. Карточки внизу продолжают показывать исходные пресеты для сравнения.
- Раскрыть расчёт: среднее по населению, слабейший район, штрафы.

## Состав и границы

- `comparison.mjs` — подготовка сравнений через существующий simulation engine и перенос проекта без мутации пресетов.
- `comparison.test.mjs` — регрессии чисел, ограничений и собственного распределения.
- `app.mjs` — объяснения, состояния сравнения, редактор и автопоказ.
- `map.mjs` — карта пяти районов, распределение проектов и схема переноса.
- `index.html` / `style.css` — новый экран без панелей первой версии.

Математика и данные импортируются из `../../docs/brief-analysis/dist/`. Они не дублируются и не изменены. Невалидный план не получает Score.

Карта использует библиотеку, стиль и геометрию из `../astana-city/`, для тайлов OpenFreeMap нужен интернет. Исходный макет сохранён. Атрибуция OpenStreetMap/OpenMapTiles/OpenFreeMap присутствует. Точки районов и пунктир переноса — обзорная схема, не адреса проектов и не маршруты строительства. География основы может включать шесть районов, расчёт и тематический слой используют пять районов датасета.

Данные учебные. Разбор и рекомендация подготовлены заранее; LLM не вызывается. В демо можно менять районы готового набора, свободный выбор любых пяти из 14 мероприятий не добавлялся. Мобильная версия отложена.

## Проверки

```sh
node --test docs/brief-analysis/test/model.test.mjs demos/astana-story/comparison.test.mjs
node --check demos/astana-story/app.mjs
node --check demos/astana-story/map.mjs
```

Браузерная приёмка: три плана, одинаковые расходы у первых двух, критические значения, отрицательный эффект экономного варианта, свой перенос школы, before/after, остановка и завершение автопоказа, все пять маркеров внутри карты.
